# 8番出口（試作 MVP）

地下通路を歩き、「いつもと違うところ」があれば引き返し、なければ進む観察ゲーム。
正しい判断を続けて 8 番の通路まで進み、そこでも正しく判断すれば地上に出てクリア。間違えると 0 番に戻る。

## 遊び方

- すぐ遊ぶ: `dist/index.html` をブラウザ（Chrome / Edge）で開く
- 公開版: https://sou-yu.github.io/exit8-game/
- 開発する: Node.js を入れて、このフォルダで
  ```
  npm install
  npm run dev      # http://localhost:5173 で起動、保存すると自動で反映
  npm run build    # dist/index.html を作り直す（公開版は docs/index.html にコピーする）
  ```

iPhone / iPad: 画面の左側を指でなぞって移動（大きく倒すと早歩き）、右側をなぞって視点、右上の Ⅱ で一時停止。スマートフォンは軽量、タブレットは標準画質から始まる。

操作: W A S D / 矢印キーで移動、マウスで視点、Shift で早歩き、Q で画質切替（高品質 / 標準 / 軽量）、F で負荷表示、Esc で一時停止。

## 異変（16種類）

| ID | 内容 | 分類 |
| --- | --- | --- |
| poster_eye | 眼科ポスターの目が赤くなり文字が変わる | A 視覚 |
| sign_arrow | 出口案内の矢印が下向き | A 視覚 |
| poster_phone | 眼科のポスターの電話番号が「03-1133-315」（ほかはそのまま） | A 視覚 |
| poster_bath | 銭湯のポスターの「みなと湯」が「みみの湯」 | A 視覚 |
| poster_manner | マナーポスターの人の頭が首から離れて白い目が付き、後ろの腕がだらりと下がる | A 視覚 |
| sign_scrawl | 出口案内の裏に赤い字で「戻れ！戻れ！戻れ！」（振り返ると見える） | A 視覚 |
| lamp_missing | 照明が1本ない | A 視覚 |
| stripe_red | 壁の帯が赤い | A 視覚 |
| door_open | ドアが少し開いている。前まで行って中の暗がりを覗き込むと、奥から男性の低いうめき声が聞こえる | C 空間 |
| ceiling_low | 天井が低い | C 空間 |
| man_smile | 通行人が満面の笑み | B 人物 |
| man_stare | 通行人が立ち止まって見つめてくる | B 人物 |
| granny_behind | 前を向いて進む間は何も起きないが、振り向くとすぐ後ろにお盆を持ったおばあさんがこちらを見て立っていて、吹き出しで「お箸捨ててね」と話しかけてくる。目をそらすとまた真後ろへ回り込むので、何度振り向いても同じ（判定通路の中だけ。通り抜けはできない） | B 人物 |
| blackout | 途中で停電する | D ホラー |
| shadow | 奥に、真っ黒で顔のない人の形の影が正面を向いて立っている（通行人のモデルを黒くしたもの。近づくと消える） | D ホラー |
| vent_blood | 換気口から赤い液体が壁を伝って垂れ、床に水たまり。しずくが落ちる音がする | D ホラー |

ルール上の調整:
- 0番の通路は必ず異変なし（通常状態を覚えるため）
- 1〜8番は 60% の確率で異変あり。直近2回と同じ異変は出さず、未発見の異変を優先
- 8番の通路は出口。ここでも異変が出る。異変がなければ進む、異変があれば引き返すと地上に出てクリア。間違えると 0 番に戻る
- 8番の出口案内は「地上へ」。矢印の異変（sign_arrow）では、この案内の矢印が逆向きになる

異変を追加するときは `src/anomalies.ts` の `ANOMALIES` に1件足し、変えたものを `resetWorld` で元に戻す。

## 確認用

- `index.html?debug` … 左上に進行番号と発生中の異変を表示
- `index.html?debug&anomaly=blackout` … 1〜8番で指定の異変を必ず出す

## ループのしくみ

通路は1本ぶんだけ作ってあり、通路の端（前進）か入口（引き返し）を越えた瞬間にプレイヤーの座標を待合の位置へ移し替えている。
前進は平行移動、引き返しは待合の中心で180度回転なので、景色は同じまま切り替わる。
番号看板はその瞬間に見えていれば古い番号のまま残し、視界から外れたときに新しい番号へ変える。

## 描画（実写に近づけるための作り）

通行人とおばあさんの人物モデル（下の「通行人のモデル」「おばあさんのモデル」）以外は外部素材を使っていない（模様・看板はすべてプログラムで生成）。
Three.js r186。変更前の画面を同じ視点で撮り、CGらしく見える原因ごとに直した。

| 変更前の原因 | 対策 |
| --- | --- |
| 壁が同じタイルの繰り返しで平面的 | 巾木・腰壁タイル（200×100mm 馬目地）・帯・上部の白い施釉タイル（約143mm角）・廻り縁の断面を押し出した壁。釉薬の艶で蛍光灯が映り込み、1枚ごとの反りで映り込みが目地ごとに少しずれる。汚れ・黄ばみ・隅の陰りは焼き込み |
| 床がプラスチックのように均一に光る | 333mm 角の磁器質タイル（御影石調の斑点、半艶）。目地は粗く、場所ごとに粗さと色がわずかに違う。映り込みはぼけた光沢までにして鏡面にはしない |
| 蛍光灯が白い板と点光源 | 乳白カバー付きの器具を面光源（RectAreaLight）にし、カバーの輝度と照らす光の強さをそろえた。色温度・明るさ・黄ばみ・管端の黒ずみに個体差。器具の側面から漏れる光で、器具まわりの天井だけがほんのり明るい |
| 接触影がない | 焼き込みの陰り（巾木・帯の下・入隅・ポスターやドアのまわり）＋ GTAO ＋ 影付きライト（PCF、bias / normalBias 調整）＋ 足もとの陰り |
| 模様の繰り返しが目立つ | 1m 周期の細かい模様に、場所ごとのむら（焼き込み）を重ねる。ループで重なる場所は同じむらになるよう対称に置く |
| 露出が高く白飛び、光のもやが広い | 照明の明るさの比を実際の蛍光灯に近づけ、露出とホワイトバランスで白い壁が明るい白に写るよう合わせた。Bloom は灯具のまわりのにじみだけ |
| 通行人が箱の組み合わせ | Blender で作った人物モデル（骨格・歩行アニメーション・笑顔の形状付き）に置き換えた |

描画の流れ: シーン（HDR, MSAA）→ GTAO → Bloom → ACES Filmic + sRGB（OutputPass）→ FXAA（標準・軽量）→ 色調（低めの彩度、陰は青みのある灰）・控えめな周辺減光・ディザ。
IBL は通路そのものを2回写した環境マップ（PMREM。白い壁どうしの照り返しを2回分）。被写界深度・色収差・画面ノイズは使わない。

| 画質 | 高品質（既定） | 標準 | 軽量 |
| --- | --- | --- | --- |
| 解像度 | 画面の最大1.5倍（上限 2560×1440 相当） | 1倍 | 0.85倍 |
| アンチエイリアス | MSAA 4x | FXAA | FXAA |
| GTAO | あり | なし | なし |
| Bloom | あり | あり | なし |
| 蛍光灯 | 面光源16灯 | 面光源16灯 | 点光源で近似 |
| 影付きライト | 4灯（1024px） | 2灯（512px） | なし |

- 平均フレーム時間が 21ms を超えると自動で1段下げる。Q キーで手動切替、`?q=0|1|2` で固定
- F キーで fps・GPU 時間（対応ブラウザのみ）・描画呼び出し数・三角形数・解像度を表示
- 器具・カバー・非常灯・天井設備・点字ブロックは InstancedMesh。面光源は 12〜18m でなめらかに打ち切る

## 通行人のモデル

Blender で作った人物モデル（`office_man_rigged.glb` 通常の顔、`office_man_smile.glb` 笑顔）を、ゲーム用に1つのファイル `src/assets/man.glb`（約1.7MB）にまとめてビルド時に HTML へ埋め込んでいる。

- 身長 約1.75m、骨 32本。歩行（Walk、1.2秒で2歩）・待機（Idle、4秒）のループと、笑顔の形状（モーフ Smile）を使う
- 普段は通常の顔。異変 man_smile ではモーフを 1 にし、顔の画像を笑顔用（`head_smile`）に差し替える
- 歩く速さは 0.71 m/秒。歩行アニメーションの歩幅に合わせ、足が床で滑らない速さにしている（`src/man.ts` の `WALK_SPEED`）
- 骨組みと歩行は `tools/man/rig.mjs` で作り直した（下の表）
- 立ち止まる異変（man_stare）では待機の動きへなめらかに切り替え、こちらへゆっくり向き直る
- 頭部の土台は MakeHuman のベースメッシュ（CC0 1.0）。顔・髪・衣服の画像は参照用に用意した写真から作ったもの

元の2ファイル（合計 約28MB）からの軽量化（`tools/man/`）:

| 項目 | 内容 |
| --- | --- |
| 画像 | PNG を JPEG に（顔は 2048px のまま、服 1448px、鞄・歯 512px） |
| 形状 | 手・シャツ・ズボン・鞄の金具だけ間引いた（18.0万 → 10.5万三角形）。顔・目・口の中・歯は元のまま |
| アニメーション | 30fps の段付き（STEP）を補間（LINEAR）にし、60fps でもなめらかに動くようにした |
| 圧縮 | 量子化（KHR_mesh_quantization）と meshopt 圧縮（EXT_meshopt_compression） |
| 笑顔 | 2つのファイルは顔の画像以外が同じなので、笑顔の顔画像だけを同じファイルに追加した |
| 骨組み | 股関節・膝・足首・指の付け根を体の形に合わせて置き直し、骨の向きをモデルの軸にそろえた |
| 手 | 元の手は左右が逆の形（親指が体の内側）だったので、手首の中心を通る面で鏡に映して直した（持っているスマホ・鞄も一緒に） |
| 重み | 元は部位ごとにほぼ1本の骨だけで動いていたので、シャツ・ズボン・靴を骨からの距離でなめらかに付け直した。顔・首・襟・手・鞄・スマホは元のまま |
| 歩行 | 脚は IK で計算（着いている足が床で滑らない、かかとから着いて指の付け根でかかとを上げて蹴る）。腰の上下・左右の揺れとひねり、胸の逆向きのひねり、腕の振り（鞄を持つ右腕は小さく） |

作り直すとき（Blender から書き出し直したとき）は、作業用フォルダに `@gltf-transform/core@4 @gltf-transform/functions@4 @gltf-transform/extensions@4 meshoptimizer@0.22` を入れ、Python の Pillow を用意して:

```
node tools/man/extract-images.cjs office_man_rigged.glb img/n
node tools/man/extract-images.cjs office_man_smile.glb img/s
python tools/man/textures.py img jpg
node tools/man/rig.mjs office_man_rigged.glb rigged.glb "$PWD/node_modules/three/build/three.module.js"
node tools/man/optimize.mjs rigged.glb src/assets/man.glb jpg
```

## おばあさんのモデル

異変 granny_behind のおばあさん（白い割烹着と三角巾、うどんの丼をお盆で運んでいる）。8方向の画像（`udon_granny_turnaround`）から作ったモデルを、ゲーム用に `src/assets/granny.glb`（約0.7MB）にしてビルド時に HTML へ埋め込んでいる。

- 身長 1.55m、約9,700三角形。体は画像から焼き込んだテクスチャ1枚、お盆・丼・うどん・ねぎは色だけの模型
- 骨は 6本（root・hips・spine・chest・neck・head）。腕とお盆は胸と一緒に動く。待機（Idle、4秒ループ）だけで歩かない
- 正面から見たときがいちばん元の画像に近い。この異変ではいつもプレイヤーのほうを向いて立つ
- 吹き出しは画面のほうを向く板（Sprite）。AO の深度に入れると四角い陰りが出るので、`src/render.ts` で AO の計算から外している

元のモデル（`udon_granny.glb`）からの軽量化は `tools/granny/optimize.mjs`（量子化と meshopt 圧縮。形は変えない）。上と同じ作業用フォルダで:

```
node tools/granny/optimize.mjs udon_granny.glb src/assets/granny.glb
```
